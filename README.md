# timothymccaslin.com

Personal projects dashboard for Timothy McCaslin.

- **Live:** https://timothymccaslin.com (GitHub Pages)
- **Stack:** static HTML/CSS/vanilla JS — no build step
- **Projects:** edit `projects/projects.json` (name, description, url, icon, status)
- **Copy:** placeholder intro/about in `index.html` are marked for editing

Palette: `#090A10` / `#2F6BFF` / `#FF7A1A`.

Do not commit passwords, API keys, or private project details.
